# PRD.md — 제품 요구사항

## 문제 정의

기존 독서 활동은 완성된 독후감·서평이라는 **결과물** 중심으로 평가되어, 학생이 책을 읽으며
겪는 **사고의 변화 과정**이 드러나지 않는다. 또한 AI 대필로 서평의 진정성이 훼손되기 쉽다.
이 앱은 문장 수집 → 해석·질문 → (산파법) → 서평으로 이어지는 과정을 기록하고,
AI가 대신 쓰지 않도록 설계한다.

## 목표 사용자

- **학생**: 스마트폰으로 문장을 수집하고 해석·질문을 남기며 서평을 쓴다.
- **교사**: 데스크톱에서 학급을 운영하고 학생 활동을 확인·평가한다.
- **관리자**: MVP에서 별도 화면 없음. 교사 권한 부여만 수동/스크립트로 처리.

## 핵심 사용자 시나리오

1. 교사가 학급을 만들고 참여 코드를 학생에게 공유한다.
2. 학생이 코드로 학급에 참여하고 학급 도서를 확인한다.
3. 학생이 인상 깊은 문장을 수집하고 선택 이유·해석·질문을 기록한다.
4. (Phase 2+) 학생이 수집 문장을 근거로 서평을 쓰고 북포스터를 제출한다.
5. (Phase 3+) 학급 갤러리에서 서로 댓글·좋아요·별점으로 피드백한다.
6. (Phase 4+) 동료평가 기반 우수작 후보가 추천되고 교사가 최종 선정한다.

## 필수 기능 (Phase 1)

- 이메일/비밀번호 인증, 프로필(공개 별칭), 로그아웃, 보호 라우트.
- 교사의 학급 생성 및 참여 코드 발급.
- 학생의 참여 코드 기반 학급 가입.
- 교사의 학급 도서 등록·목록.
- 학생의 문장 카드 작성·목록·상세·수정·삭제, 도서별 필터, 태그.
- 교사의 담당 학급 문장 기록 조회.

## 제외 기능 (Phase 1)

서평 · 북포스터 업로드 · 갤러리 · 댓글 · 좋아요 · 별점 · 우수작 계산 · AI 챗봇 ·
알림 · PDF 출력 · 통계 대시보드 · Google OAuth. (미리 빈 화면/버튼을 만들지 않는다.)

## 기능별 인수 조건 (Phase 1)

- **인증**: 회원가입 시 role은 반드시 student. 미인증 사용자는 보호 페이지 접근 시 로그인으로 이동.
- **학급 생성**: 교사만 성공. 학생 시도는 RLS로 거부. 생성 후 참여 코드가 교사에게만 표시.
- **학급 참여**: 유효 코드 → 가입, 재시도 → "이미 가입됨", 오류 코드 → 정보 노출 없이 거부.
- **도서**: 담당 교사만 등록. 구성원은 조회.
- **문장 카드**: quote/reason/interpretation 필수. 본인만 수정·삭제. 다른 학생 카드 접근 불가.
  담당 교사는 조회 가능(수정 불가).
- **품질 게이트**: `lint`, `typecheck`, `test`, `build` 통과.
